# Shagga Gallery

Drop your extra images in this folder, named `1.jpg`, `2.jpg`, ..., `40.jpg`.

Then in `components/imageManifest.ts`, set:
- `galleryCount` to the number of images you have
- `galleryExt` to the right file extension (`.jpg`, `.png`, etc)

The Shagga Gallery app on the desktop will display all of them in a clickable grid.
