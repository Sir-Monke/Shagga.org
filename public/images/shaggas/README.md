# Drop "Top Shagga" Photos Here

Name them: `1.jpg`, `2.jpg`, `3.jpg`, ... up to however many you have.

These appear in the **"Top Shagga's In Your Area"** popups.

If you change how many images you have, edit `shaggasCount` in
`components/imageManifest.ts` (top of repo).

If your images are .png instead of .jpg, edit `shaggasExt` in the same file.
