# Drop "For Sale" Product Images Here

Name them: `1.jpg`, `2.jpg`, `3.jpg`, ... up to however many you have.

These appear in the **"Shagga Item For Sale!"** popups (the random ones with prices).

If you change how many images you have, edit `productsCount` in
`components/imageManifest.ts` (top of repo).

If your images are .png instead of .jpg, edit `productsExt` in the same file.
